- [ ] **Create the Firebase project** with a NEUTRAL id, `familyhub-prod` if it is free (a project id can never be renamed and it will outlive the repo; never `johnnyjansen-*`). If the id is taken, pick another neutral one and change it in the eight places `grep -rn familyhub-prod` lists. Personal Google account, Blaze plan (scheduled functions and outbound Google API calls need it). Enable Firestore (production mode, `nam5`), Authentication → Google provider, Cloud Functions, App Check, and Cloud KMS (one key ring `familyhub`, one key `google-tokens`).

- [ ] **Set the params.** Locally: copy `functions/.env.example` to `functions/.env`: `TIMEZONE`, and `KMS_KEY` (the full resource name of the `google-tokens` key). Grant the functions' service account (`<project-number>-compute@developer.gserviceaccount.com`) the *Cloud KMS CryptoKey Encrypter/Decrypter* role on that key. There is no owner email: the first person to sign in and found a household is the first adult.
