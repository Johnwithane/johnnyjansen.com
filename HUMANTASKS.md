# Human tasks

Things only Johnny can do. Tick them off in order; each phase's code assumes the ones above it.

## Phase 0: get the portal live

- [x] Answer the open questions (2026-09-19: Gmail, everything on Firebase, 6:30am, new environment).
- [ ] **Create the Firebase project** with a NEUTRAL id, `familyhub-prod` if it is free (a project id can never be renamed and it will outlive the repo; never `johnnyjansen-*`). If the id is taken, pick another neutral one and change it in the eight places `grep -rn familyhub-prod` lists. Personal Google account, Blaze plan (scheduled functions and outbound Google API calls need it). Enable Firestore (production mode, `nam5`), Authentication → Google provider, Cloud Functions, App Check, and Cloud KMS (one key ring `familyhub`, one key `google-tokens`).
- [ ] **Register a web app** in the project and copy its config into a GitHub *variable* set: `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_PROJECT_ID`, `VITE_FIREBASE_APP_ID` (repo Settings → Secrets and variables → Actions → Variables). Same values into a local `portal/.env` for dev.
- [ ] **Set the params.** Locally: copy `functions/.env.example` to `functions/.env`: `TIMEZONE`, and `KMS_KEY` (the full resource name of the `google-tokens` key). Grant the functions' service account (`<project-number>-compute@developer.gserviceaccount.com`) the *Cloud KMS CryptoKey Encrypter/Decrypter* role on that key. There is no owner email: the first person to sign in and found a household is the first adult.
- [ ] **Turn on Google Authenticator as a second factor** in Authentication → Sign-in method → Multi-factor (TOTP). Adults will be asked for it before Money, Taxes and the Vault.
- [ ] **Google OAuth client (Phase 1c wires it).** Google Cloud console → APIs & Services → enable *Google Calendar API* and *Gmail API* → OAuth consent screen (External; add both your Gmail addresses as test users while it stays in Testing) → Credentials → OAuth client, type **Web application**, redirect URI `https://us-central1-familyhub-prod.cloudfunctions.net/googleOAuthCallback`. Then `firebase functions:secrets:set GOOGLE_OAUTH_CLIENT_ID` and `GOOGLE_OAUTH_CLIENT_SECRET`. Each adult connects their own Google from the Household screen; no local token minting. A consent screen left in Testing expires grants after 7 days, so publish it once both of you have connected.
- [ ] **First deploy** from a machine logged into Firebase: `npm run deploy:rules && npm run deploy:functions && npm run deploy:hosting`. Open `https://familyhub-prod.web.app/app`, sign in with Google, found the household (Step 1), add the kids and create Carly's invite link on the Household screen, send it to her.
- [ ] **DNS cutover.** Firebase Hosting → Add custom domain `johnnyjansen.com` (and `www`), then replace the GitHub Pages A/CNAME records at the registrar with the ones Firebase gives you. Add `johnnyjansen.com` to Authentication → Settings → Authorized domains. Once it resolves to Firebase: turn off GitHub Pages in the repo settings and delete the root `CNAME` file (a later commit can also move the portfolio into `site/`). `PORTAL_URL` in `functions/src/digest/runDigest.ts` already says `https://johnnyjansen.com/app`.
- [ ] **Feedback loop secrets.** `openssl rand -hex 32` → `firebase functions:secrets:set CI_FEEDBACK_TOKEN` AND the same value as the GitHub secret `CI_FEEDBACK_TOKEN` (CI calls markFeedbackShipped with it after every deploy). A fine-grained GitHub PAT with Issues read/write on this repo → `firebase functions:secrets:set GITHUB_FEEDBACK_TOKEN` (`me feedback dispatch` opens issues with it; until set, dispatch says so).
- [ ] **CI deploys.** Create a service account key with Firebase Admin + Cloud Functions Developer + Service Account User roles, store it as the GitHub secret `FIREBASE_SERVICE_ACCOUNT`, then set the GitHub variable `FIREBASE_DEPLOY_ENABLED=true`. Until then the workflow only checks.
- [ ] **Claude Code environment.** On the Household screen tap Mint token (Claude Code access) and copy it. In claude.ai/code → Environments, create `johnnyjansen` with the env var `ME_TOKEN=<that token>`. Then in any session: `npm run me today`. Carly can mint her own.
